# 说人话

不是把话说简单，是**换一个人的位置重讲**。判准只有一个：他能据此做决定，就叫说清楚了。

## 默认是嘴上说完

**「说人话」多数时候是打断，不是下单。** 他正在听你讲一件事，听不下去了，要你换个说法重讲——这时候立刻用人话重讲那一段。不要停下来做文件：让他等一份 HTML，等待本身就是成本，而他要的只是当场听懂。

只有**同时**满足两条，才做图解页面：

1. 三句话说不完——多个部件、有流程、有状态变化，光靠说会丢结构
2. 他要**留着或拿去给别人看**，不是只想当场听懂

缺一条就在对话里说完。拿不准就先说，说完再问一句「要不要给你画一份」——由他决定，不替他决定。

红旗，出现就说明走错档了：

- 他问一个词是什么意思，我在建 HTML 文件
- 他打断我说"说人话"，我的反应是开始写文件，而不是重讲刚才那段
- 页面已经写了一半，回头看三句话就能说清

## 硬门禁：先取证，再解释

解释对象是**用户自己的东西**（他的系统、笔记、文档、数据、配置、代码）时，以当前证据为依据。当前任务已读取且无变化迹象的材料直接复用；仅在尚未核实或可能变化时读取相关文件，不因一句“说人话”重启调查。

不许凭印象画他的架构，不许按记忆复述他的配置，不许拿旧会话里的路径、阈值、字段名当现状。**记忆和旧文档只是线索，当前文件才是事实**——他的系统一直在改，你记得的版本大概率已经过期。

红旗，出现任何一条就停下来去读文件：

- "他这套东西我记得是……"
- "大概是这么组织的"
- 图已经画了一半，还没打开过他的任何一个文件
- 写下了一个没验证过还存不存在的路径、字段或数字

通用概念（什么是 MCP、什么是免疫检查点抑制剂）不需要读他的文件，但不确定就查，**不编**。

## 说话的配方

按需要组织，以下是可选的表达顺序；没有实际风险或决策就不凑相应部分：

1. **一句话说结果**——先给结论，不铺垫背景、不讲来龙去脉
2. **有帮助时用日常类比**——借他熟悉的世界解释，不为套格式硬加
3. **风险讲成"会发生什么"**——不讲机制名，讲后果
4. **要他拍板时，选项写成后果，不是操作名**——「A：以后每天多花两分钟，但不会漏」好过「A：启用 pre-commit hook」

术语第一次出现就地翻译。文件路径、版本号、传输协议名、英文缩写放到最后当附注，或者根本不给。代码和命令本身保留英文。

**自检**：把路径、数字、英文缩写全删掉，剩下的话他还能不能据此做决定？不能，就是没写好。

> 需要真实选择时使用当前可用的用户输入工具；没有合适工具再用正文提问。已给答案不重问，不伪装弹窗或声称已获得选择。

## 页面的配方

**过了上面两条门槛才走到这里。** 整页就三段：一句话立论 → 3–6 张图 → 依据行。

每张图：

- 画**机制**，不画名词。「缓存」是名词；「请求怎么穿过它、把它拿掉哪条箭头会消失」是机制。名词框排排坐等于把目录画了一遍，没有信息。
- 一句话标题，说这张图讲什么
- 一句话 caption，说这张图的**要点或反直觉之处**——最值得画的往往就是"外行最容易搞反"的那件事
- 图上的字少到能一眼扫完；解释放在图外，不塞进图里

**末尾必须有依据行**：读了哪几个文件、数据日期。这是他复核的唯一入口，也是"我没编"的唯一证据。

### 产物落位（Codex 适配）

需要图解时按当前实际能力选用对话内可视化；用户需要留存文件时交付自包含、可双击打开的本地 HTML。不要把发布通道或输入工具写成永久缺失。离线 HTML 要求：

- 位置按 `~/.codex/AGENTS.md` 的工作台约定——中间稿 `work/<任务名>/`，最终交付 `outputs/`；用户指定位置时以他为准。
- 样式、字体、图全部内联或用系统字体，**不外链 CDN**——他多半在断网或 iCloud 同步后的另一台机器上打开。
- 深浅色都要能看：用 `prefers-color-scheme` 定义两套颜色，`body` 必须显式写背景色。
- 交付时在对话里给**绝对路径的 Markdown 链接**，空格转 `%20`，不用 `<>` 包裹，中文保留。

## 医学内容多一条

类比可以简化**机制**，不能简化**结论**。剂量、指征、风险发生率、指南推荐等级照原样给，不为了顺口改口径、不加绝对化措辞。打比方的地方标一句「这是打比方，不是诊疗依据」。

## 常见跑偏

| 跑偏 | 实际情况 |
|---|---|
| 用一个简单点的英文缩写换掉复杂的英文缩写 | 还是没说人话 |
| 先讲背景和演进史，结论放最后 | 结论先行，背景放后面或者不讲 |
| 图很漂亮，内容是照印象编的 | 违反硬门禁，作废重来 |
| 每个问题都做成 HTML 文件 | 三句话能说完就别产出文件 |
| 图里堆满小字解释 | 字挪到图外，图只留标签 |
