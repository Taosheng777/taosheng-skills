# MiniMax H3 制作中控

用户 2026-10-26 指定 Codex 为制作中控与总指挥：用户讲需求，Codex 负责组织执行并交付可用完整片。旧的“视频只能留 Claude、不可迁入 Codex”已被本次决定替代。不要把任务停在分工计划、关键帧或第一版；明确要求先规划/只交音乐时仍遵守原范围。

## 开工入口

- 媒体工作台 `<你的工作目录>/Minimax视频/`：读项目 `00-先看这里.md`、当前状态及适用 `AGENTS.md`。归档作品先看归档说明，不自动续做。
- 工具权威源 `~/Library/Mobile Documents/com~apple~CloudDocs/<你的项目工作区>/23-视频工具链/`：H3 任务读 `AGENTS.md` 与 `docs/H3主力与Codex剪辑工作流.md`，安全任务封装在 `h3-workflow/tools/`。不要从空的旧 `10-mac_h3_video_workflow` 启动。
- 创作、提示词、生成与声音经验读 [H3制作经验](references/H3制作经验.md)；脚本命令与分派读 [执行与验片](references/执行与验片.md)。不整读全部旧日志或图像。
- 本 skill 的维护源在工具链 `codex-skills/minimax-h3-director/`；本机运行副本在 `~/.codex/skills/minimax-h3-director/`。修改后按文件同步并核对，保留他人变更。

## 分工与完成标准

Codex 掌握故事、镜头意图、审美取舍、预算、调度、合片和最终交付；可将独立脚本/整理任务委派给 subagent，明确文件所有权及验收。Gemini 做批量抽帧查错、人物道具连续性和文字可读性检查，一次合并、串行调用。DeepSeek 是后续可接入选项，不能把搜索工具当视频审片能力，也不因提到它就擅自开通付费模型。

主会话只看结构化问题表及少量关键疑点。优先脚本全片技术扫描、带时间码拼图和内容哈希缓存；没有新片或新问题不重复整片抽帧审查。重要未决疑点不能因标为“存疑”而忽略。只修有证据的受影响片段。

完成片包含可播放 MP4、必要声音与字幕、最终时长/规格、原片及工程入口、技术结果、视觉检查范围与未决项，并更新视频看板。制作完成、用户终审和发布分别记录，不能互相替代。Gemini 看拼图不代表连续动作验证，更不代表完整听过；有音频能力才能报告实际听检，ASR 也不能代替听感。

## 执行边界

- H3 本地路线用 Qwen/H3 生成主体，FFmpeg 后期；不以代码动画或静帧掩盖失败的已约定动态镜头。不同路线或服务按本次作品需求与授权选择。
- 继承具体作品已有关键帧/动作/规格审阅点；已获同范围授权不反复问。历史 JSON 是冻结证据，不改其审批字段以假装获准。旧《回信》的门槛不自动成为所有新片的额外访谈。
- Windows 一张 GPU 串行，提交前查队列；不打断外来任务。不直接用有无条件重启副作用的旧 `local/h3.py`。提交意图、prompt_id、工作图和回收哈希持久化；断线/超时先对账，状态不明不重投、不强杀。
- 保留用户既有 Windows 安静时段：优先 08:00–17:00，17:00–23:00 开跑须有当次明确授权，23:00 后不跑；用户明确指定的单次时段优先。默认按用户当前时区解释，开 GPU 前核对预计结束时间与用户是否正在使用机器。迁移不自动创建后台等待循环或定时任务。
- 本机大任务前用 `~/.config/macmini-storage/ssd-workspace check` 核验 UUID。中间文件和 H3 成片放 SSD 项目目录，小型源码/记录保留现有 iCloud 工具台；不搬动凭据、不恢复 Claude 登录态。
- 云端费用、模型下载、发布沿用真实授权。旧价格、旧“30 元以内直接用”及旧账号能力不是新的付费授权；使用前核对当前已获范围。Gemini 限额/登录失败如实报告，继续独立准备，不循环重试或静默切换收费模型。
