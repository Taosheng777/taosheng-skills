# A 股数据工具包

需要真实取数时使用。按任务选择下面的领域参考，不必通读全部资料。代码、脚本和原有数据契约保留；文中的实测日期是历史证据，本次运行仍须核对来源、数据日期、标的和字段口径。

当前为**本机定制版 + v3.10.2 正式版手册（2026-10-25）**。上游手册固定到提交 `29b07d2e37005b9fd568bca1262f6e572b5f9407`；已按领域拆分，包含新版腾讯行情、基金/期货来源及估值修复。本机市场宽度、板块缓存和日快照脚本保留原有实现，不把手册更新宣称为这些脚本已重写。

## 取数边界

- 行情、K 线和盘口优先腾讯；单日全市场与真实成交额用通达信官网盘后包；mootdx 仅财务/F10，按 `check="finance"` 验活；财报、公告等按领域选择新浪、巨潮、同花顺。东财用于其独有数据；不得编造缺失结果或把源故障写成“没有数据”。
- 所有东财请求经过共用 `em_get()`：串行、复用会话、正常 UA / Referer、每次至少 1 秒并加随机抖动；批量任务适当降速。不要对东财并发，也不要以换代理扩大请求量。
- 板块逐日资金史去单点：走 `scripts/board_fund_flow_cache.py`，SQLite 缓存优先，可选 Tushare DC 补洞；`push2his fflow/daykline` 只做持久熔断允许的单次探测，禁止逐板块循环直连。精确检查结束日期和覆盖；THS 分类不得混入 DC 时间序列，不覆盖已有东财值。
- 行业排名用 `scripts/industry_ranking.py`：精确日期、同一东财分类的已验证完整缓存优先；否则全量分页后排序。缓存缺宽度/领涨字段时明确留空，不把第一页末列当全市场跌幅榜。
- 市场宽度以腾讯源字段的涨跌停价判定，不按名称猜 ST 限幅。`breadth_reconcile()` 非零差异保留双方值并标“口径异常”，不得静默放行。
- 主源失败时按 [备用源与降级](references/备用源与降级.md) 选择独立备份；仍无可核验数据就明确本项未验证。涉及 API Key 时只使用现有获准凭据，不输出秘密。

- 腾讯 K 线默认前复权；历史实际成交价核对显式 `adjust=""`，不可把复权价直接当纪律止损。量为手，不含成交额；北交所日线用盘后包，包内证券不限 A 股，须按市场+代码筛选。
