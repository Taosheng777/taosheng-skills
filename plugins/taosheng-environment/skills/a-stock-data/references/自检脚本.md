## 自检脚本

脚本都在 `scripts/`，纯标准库 + requests，直接跑无需参数。**改了对应章节的端点代码后必须复跑**。

| 脚本 | 覆盖 | 何时跑 |
|---|---|---|
| `test_industry_ranking.py` | 完整行业排名、精确日期、缓存凭证、全量分页、缺页与重复代码 | 修改行业排名或快照覆盖登记后；离线运行 |
| `test_market_upgrade.py` | 本地发布代码：路由/龙虎榜空结果/市值字段/财务验活/腾讯K线/盘后包完整性 | 修改本轮合并部分后；离线运行 |
| `smoke_test.py` | §1.2 腾讯行情 · §7.1 解禁日历 · 巨潮公告（3 项） | 改动基建（`em_get`、`UA`、限流）或上述三节后 |
| `test_v3_backbone.py` | **§3.3 概念归属 · §3.7 行业排名（含降序校验）· §3.8 板块资金流 3 类板块 × 3 周期 · §3.8 板块逐日缓存 · §3.11 腾讯封板价字段与 ST 反例**（16 项） | 改动 §3.3 / §3.7 / §3.8 / §3.11 后 |
| `test_board_fund_flow_cache.py` | **SQLite 幂等 · 导入去重与哈希 · 跨源冲突 · Tushare DC 映射/锚点审计/缺失项回填/断点续跑/类型归一 · 全板块分页与数据日 Gate · 历史覆盖 Gate · push2his 单探测/持久熔断**（23 项） | 改动 `board_fund_flow_cache.py` 或 §3.8 逐日史后 |

```bash
python3 ~/.codex/skills/a-stock-data/scripts/test_market_upgrade.py
python3 ~/.codex/skills/a-stock-data/scripts/smoke_test.py
python3 ~/.codex/skills/a-stock-data/scripts/test_v3_backbone.py   # 全通时退出码 0
python3 ~/.codex/skills/a-stock-data/scripts/test_board_fund_flow_cache.py
```

**为什么 v3 主干单独一个脚本**：投资笔记 v3 的降级链把本 skill 定为**零额度首选源**（问财额度有限，能在这里拿到的一律不许调问财），而主干正是 §3.3 / §3.7 / §3.8 / §3.11 —— `smoke_test.py` 原本一个都没覆盖。2026-08-05 补齐前三节，2026-08-11 加入封板价源字段与已确认 ST 反例回归。

**代理注意**：`test_v3_backbone.py` 已内置 `EM_SESSION.trust_env = False`，本机设了 `HTTPS_PROXY` 也能直连东财。`board_fund_flow_cache.py` 同样显式忽略环境代理，避免代理轮换放大历史端点风控；`smoke_test.py` 未内置，走代理的环境下需 `env -u HTTP_PROXY -u HTTPS_PROXY python3 scripts/smoke_test.py`。
