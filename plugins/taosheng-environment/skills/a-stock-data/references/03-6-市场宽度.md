### 3.11 市场宽度 — 涨跌家数 / 涨停跌停（问财家数口径的零额度影子源）

**为什么有这一节**：投资笔记 v3 复盘的五档环境判定依赖「沪深A股全池、含 ST」的涨跌家数，此前只认问财——额度有限、且**无法复核**（单点风险）。2026-08-07 实测证明本函数能**逐位复现**问财口径：

| 指标 | `market_breadth()` | 问财 2026-08-07 | 差 |
|---|---:|---:|---:|
| 上涨家数 | 2671 | 2671 | **0** |
| 下跌家数 | 2399 | 2399 | **0** |
| 跌停 | 4 | 4 | **0** |
| 涨停（含 ST） | 75 | 74 | +1 |

涨停那 +1 已定位到具体一只：`000078 ST海王`——收盘确实封在涨停价（`收盘 == round(昨收×1.05, 2)`），但显示涨幅只有 4.82%（低价股涨停价四舍五入所致），问财按涨幅口径少算了它。本函数因此**单独返回 `limit_up_st`**，供现行对账规则记录 ST 封板数；它只是描述字段，不能再解释为「问财不含 ST」。

**2026-08-11 反例与修复**：旧 `_price_limit(code, name)` 把「名称含 ST 的主板股」一律按 5% 计算，漏掉了当日按 10% 封板的 `600107 *ST尔雅`（昨收 5.24 → 收盘/腾讯涨停价 5.76）和 `600759 ST洲际`（昨收 2.33 → 收盘/腾讯涨停价 2.56），造成影子 58 vs 问财 60。2026-08-10 的问财 103/5 vs 旧影子 100/6 也是同类启发式失配信号，但尚未逐只归因。现改为直接读取腾讯行情字段 47/48；**股票名称只用于统计 `limit_up_st`，不参与封板价计算**。

**口径定义（与问财对齐，改动即破坏历史序列可比性）**

- 池子 = 沪深A股全池 = `fs=m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23`（深主板+中小 · 创业板 · 沪主板 · 科创板）
- **含 ST、不加任何过滤**；**不含北交所**（问财「沪深A股」也不含，加进去会多出 ~300 只）
- 涨 / 跌 / 平按 `f3` 符号；`f3` 无值 = 停牌或无报价，**单独计数、不进涨跌家数**
- 涨停 / 跌停按**行情源给出的当日封板价**判定，不按涨幅阈值或名称推断：`收盘价 == 腾讯字段 47/48（涨停价/跌停价）`
- 腾讯封板价按 80 只一批读取；有效报价若缺字段则计入 `limit_price_missing`，`breadth_reconcile()` 必须报口径异常，不能回退到「ST=5%」等启发式

```python
BREADTH_FS = "m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23"   # 沪深A股全池（不含北交所）
BREADTH_URL = "https://push2delay.eastmoney.com/api/qt/clist/get"

def _tencent_limit_prices(codes: list[str], batch_size: int = 80) -> dict[str, dict]:
    """批量读取腾讯行情字段 47/48（当日涨停价/跌停价），不按名称推断限制比例。"""
    import urllib.request

    out = {}
    for i in range(0, len(codes), batch_size):
        batch = codes[i:i + batch_size]
        prefixed = [("sh" if c.startswith(("6", "9")) else "sz") + c for c in batch]
        req = urllib.request.Request("https://qt.gtimg.cn/q=" + ",".join(prefixed))
        req.add_header("User-Agent", "Mozilla/5.0")
        try:
            text = urllib.request.urlopen(req, timeout=15).read().decode("gbk")
        except Exception as e:
            print(f"[WARN] 腾讯涨跌停价批次请求失败: {e}")
            continue
        for line in text.strip().split(";"):
            if "=" not in line or '"' not in line:
                continue
            vals = line.split('"')[1].split("~")
            if len(vals) <= 48 or not vals[2]:
                continue
            try:
                limit_up, limit_down = float(vals[47]), float(vals[48])
            except (TypeError, ValueError):
                continue
            out[vals[2]] = {"limit_up": limit_up, "limit_down": limit_down}
    return out

def _price_limit(code: str, source_quote: dict | None) -> tuple[float | None, float | None]:
    """返回行情源给出的当日涨停价/跌停价；字段缺失即返回空，不做名称启发式 fallback。"""
    if not source_quote:
        return None, None
    try:
        limit_up = float(source_quote.get("limit_up") or 0)
        limit_down = float(source_quote.get("limit_down") or 0)
    except (TypeError, ValueError):
        return None, None
    if limit_up <= 0 and limit_down <= 0:
        return 0.0, 0.0          # 上市首日等无涨跌幅限制，腾讯当前返回 -1/-1
    if limit_up <= 0 or limit_down <= 0:
        return None, None
    return round(limit_up, 2), round(limit_down, 2)

def market_breadth(verbose: bool = False) -> dict:
    """沪深A股全池市场宽度：涨跌家数 + 涨停跌停（零额度，东财 push2）。

    口径对齐同花顺问财「沪深A股」全池含 ST，2026-08-07 实测涨跌家数逐位一致。
    约 56 次分页请求（东财 clist 单页硬上限 100 条，pz 传再大也只回 100），
    走 em_get 限流，全程约 60–80 秒。**每日一次，勿放进循环。**

    返回 dict：
      total/up/down/flat/no_quote/ratio · limit_up/limit_down/limit_up_st ·
      limit_price_missing/limit_price_unlimited · detail
    """
    EM_SESSION.trust_env = False       # 本机走代理时必须关；否则东财主域返回 Empty reply
    rows, pn = [], 1
    while True:
        r = em_get(BREADTH_URL, params={
            "pn": pn, "pz": 100, "po": 1, "np": 1, "fltt": 2, "invt": 2,
            "fid": "f3", "fs": BREADTH_FS, "fields": "f12,f14,f3,f2,f18",
        }, headers={"Referer": "https://quote.eastmoney.com/"}, timeout=25)
        d = r.json().get("data")
        if not d:
            break
        rows += d.get("diff") or []
        if len(rows) >= d.get("total", 0):
            break
        pn += 1
        if pn > 120:                   # 防跑飞
            break

    quote_codes = [str(x.get("f12") or "") for x in rows
                   if x.get("f12") and isinstance(x.get("f2"), (int, float))
                   and isinstance(x.get("f18"), (int, float)) and x.get("f18") > 0]
    source_limits = _tencent_limit_prices(quote_codes)

    up = down = flat = no_quote = 0
    lu, ld, lu_st, limit_price_missing, limit_price_unlimited = [], [], 0, [], []
    for x in rows:
        chg = x.get("f3")
        if isinstance(chg, (int, float)):
            if chg > 0:   up += 1
            elif chg < 0: down += 1
            else:         flat += 1
        else:
            no_quote += 1
        code, name = str(x.get("f12") or ""), str(x.get("f14") or "")
        price, prev = x.get("f2"), x.get("f18")
        if not code or not isinstance(price, (int, float)) \
           or not isinstance(prev, (int, float)) or prev <= 0:
            continue
        limit_up, limit_down = _price_limit(code, source_limits.get(code))
        if limit_up is None or limit_down is None:
            limit_price_missing.append((code, name))
            continue
        if limit_up == 0 and limit_down == 0:
            limit_price_unlimited.append((code, name))
            continue
        if abs(price - limit_up) < 0.005:
            lu.append((code, name, chg))
            if "ST" in name.upper().replace(" ", ""):
                lu_st += 1
        elif abs(price - limit_down) < 0.005:
            ld.append((code, name, chg))

    out = {
        "total": len(rows), "up": up, "down": down, "flat": flat, "no_quote": no_quote,
        "ratio": round(up / down, 3) if down else None,
        "limit_up": len(lu), "limit_down": len(ld), "limit_up_st": lu_st,
        "limit_price_missing": len(limit_price_missing),
        "limit_price_unlimited": len(limit_price_unlimited),
        "detail": {"limit_up": lu, "limit_down": ld,
                   "limit_price_missing": limit_price_missing,
                   "limit_price_unlimited": limit_price_unlimited},
    }
    if verbose:
        print(f"全池 {out['total']} 只 | 涨 {up} / 跌 {down} / 平 {flat} / 无报价 {no_quote}"
              f" | 涨跌比 {out['ratio']}")
        print(f"涨停 {len(lu)}（其中 ST {lu_st}）/ 跌停 {len(ld)}"
              f" | 无涨跌幅限制 {len(limit_price_unlimited)}"
              f" | 封板价字段缺失 {len(limit_price_missing)}")
    return out

def breadth_reconcile(wencai_up: int, wencai_down: int,
                      wencai_zt: int, wencai_dt: int, shadow: dict) -> dict:
    """把问财四问句的 code_count 与影子值对账。投资笔记复盘每日必跑。

    判定：涨跌家数与涨停家数必须逐位相同；limit_up_st 仅为描述字段，
    不再作为自动容差。任一项超界 → ok=False，复盘须逐股核对，不得静默写入。
    """
    d_up, d_dn = shadow["up"] - wencai_up, shadow["down"] - wencai_down
    d_zt, d_dt = shadow["limit_up"] - wencai_zt, shadow["limit_down"] - wencai_dt
    missing = shadow.get("limit_price_missing", 0)
    ok = (missing == 0 and d_up == 0 and d_dn == 0
          and d_zt == 0 and abs(d_dt) <= 1)
    return {"ok": ok, "d_up": d_up, "d_down": d_dn, "d_zt": d_zt, "d_dt": d_dt,
            "st_limit_up": shadow["limit_up_st"], "limit_price_missing": missing,
            "note": "一致" if ok else "口径异常：需人工核对，不得静默写入"}
```

```python
# 用法 —— 复盘每日一次
b = market_breadth(verbose=True)
# 全池 5547 只 | 涨 2671 / 跌 2399 / 平 132 / 无报价 345 | 涨跌比 1.113
# 涨停 75（其中 ST 1）/ 跌停 4

# 与问财四问句 code_count 对账
print(breadth_reconcile(2671, 2399, 74, 4, b))
# {'ok': False, 'd_up': 0, 'd_down': 0, 'd_zt': 1, 'd_dt': 0,
#  'st_limit_up': 1, 'limit_price_missing': 0, 'note': '口径异常：需人工核对，不得静默写入'}
```

> **已知边界**：① 上市首日等无涨跌幅限制标的以腾讯字段 47/48 的 `-1/-1` 为准，单列 `limit_price_unlimited`；只有行情未返回或字段一正一非正才算 `limit_price_missing` 并 fail-closed，不再启发式补算。② 2026-08-11 已证伪「问财涨停不含 ST」和「主板名称含 ST 即 5%」两项假设；`limit_up_st` 仅保留为描述字段，任何非零涨停差都须逐股核对，不能自动归因为 ST。③ 本函数**不替代**问财成为写入源，只做强制校验与额度耗尽时的备用值（规则见投资笔记 `00-系统/AI操作规则.md` §问财额度纪律 ⑤）。
