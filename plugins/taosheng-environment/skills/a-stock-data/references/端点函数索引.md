## 端点路由速查（按需定位，不必通读全文）

只需一类数据时，按下表定位章节（§）局部读取。除 iwencai 需 API Key 外全部零 key。

> **改完本文件的端点代码，必须复跑自检脚本**（见「[自检脚本](自检脚本.md)」一节）：`scripts/smoke_test.py`、`scripts/test_v3_backbone.py` 与 `scripts/test_board_fund_flow_cache.py`。端点静默失效是本 skill 最主要的失败模式——调用方（尤其投资笔记 v3）把这里当零额度主干，挂了不会报错，只会悄悄退回去烧问财额度。
