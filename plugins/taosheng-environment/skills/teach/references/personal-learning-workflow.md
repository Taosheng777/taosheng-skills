# 个人学习工作流

本文件只在教学需要读取用户个人工作记录、建立多会话状态或向 Obsidian 沉淀时使用。

## 信息源与职责

| 信息源 | 用途 | 默认权限 |
|---|---|---|
| `我的成长史` vault | 了解活跃目标、时间约束和真实学习动机 | 只读；不写课程笔记 |
| 当前项目的 `DESIGN.md` / `PROGRESS.md` | 了解项目事实和当前能力缺口 | 只读；除非项目任务明确要求修改 |
| 独立学习工作台 | 保存多会话学习状态、材料和可读课程产物 | 用户确认位置后写入 |
| `读书笔记` vault | 读取既有文章；保存用户明确要求留下的最终文章 | 未经当轮明确要求不写入 |

当前 `读书笔记` 的事实源是其 `AGENTS.md`、`00-系统/PROGRESS.md` 和 `00-系统/DESIGN.md`。它是个人阅读与思考库：一次输入默认形成一篇愿意重读的文章，不恢复默认知识卡、来源笔记、主题地图、复习日期或强制周复盘。

## 适合的学习类型

### 临床推理

使用虚构病例、已获授权的私人病例材料或用户既有文章。保持以下循环：

1. 给出必要信息，让用户先判断。
2. 保留原回答与推理顺序。
3. 区分病例事实、个人理解、循证结论、适用边界和待核实项。
4. 纠正最重要的机制或流程错误。
5. 改变一个条件，验证能否迁移。

剂量、诊断和处置练习只形成学习框架，不能自动转化为真实患者处方或诊疗决定。

### 心理咨询与临床沟通

从跟诊、访谈或文章中的真实沟通难题出发，练习开放提问、反映性倾听、风险闭环、家庭系统视角和边界表达。保留用户的现场感受，再补充专业分析；不要把临床假设写成事实。

家庭与沟通案例优先使用以下推理链：

```text
可观察互动 → 暂时性结构或机制假设 → 其他可能解释 → 循环与边界
```

避免把一次互动写成稳定人格、唯一病因或“最根本的问题”。

### 科研方法

优先结合正在进行的真实项目教授研究设计、偏倚、数据口径、统计解释和论文批判性阅读。教学只解释和训练方法，不替代项目的正式方案、投稿执行或伦理决策，也不静默修改项目文件。

研究设计案例按以下顺序训练：

```text
研究问题或 estimand
→ 基线纳入条件
→ 暴露定义与测量窗口
→ 结局定义与风险窗口
→ 偏倚、混杂和测量误差
→ 结果实际允许的结论
```

特别区分：

- 未确认基线时不存在结局，通常不能把随访阳性都称为新发结局。
- 用结局发生后的数据定义此前暴露，会破坏目标时间顺序。
- 不继续测量暴露不一定破坏基线暴露问题，但会限制对持续或累计暴露的解释。
- 时间顺序自洽仍不等于因果成立；先明确研究想估计的量，再讨论混杂和其他偏倚。

### 证书课程

从教材目录、考试大纲或用户提供的课程材料中选择一个可完成目标。使用短课、开放回忆和错因反馈，不自动建立周计划、打卡系统或学分完成记录。

### AI 与工具

先判断现成工具能否直接解决当前问题。一次性任务优先使用工具；只有用户明确想掌握可复用原理或操作能力时才教学，避免把工具使用变成不必要的技术课程。

## 来源优先级

医学与临床主题依次优先：

1. 当前有效的权威指南、共识与本院正式流程
2. 系统综述或高质量证据总结
3. 与问题直接相关的原始研究
4. 教科书或权威机构教育材料
5. 专家经验和病例讨论，明确标为经验或假设

工具与工作流主题优先官方文档、源代码和第一方说明。每个关键结论保留可追溯链接、版本或日期；无法定位精确来源时标明待核实。

一次短课通常只需两到四个直接相关来源。先在对话中建立来源基线，后续复用；新问题超出原来源范围时再补充。单次短课不为来源单独创建文件。

## 多会话文件格式

`DESIGN.md` 保持短小：

```markdown
# DESIGN — 学习主题

## 为什么学
一到三句话描述真实工作或生活目标。

## 成功标准
- 能在什么真实情境中完成什么动作
- 能识别什么边界或常见错误

## 约束
- 可用时间、已有基础、材料和风险边界

## 不学什么
- 当前明确排除的相邻主题
```

`PROGRESS.md` 只保存影响下一课的信息：

```markdown
# PROGRESS

## 当前能力
- 掌握层级：未展示 / 初步识别 / 已迁移
- 支持该层级的具体回答或行为

## 误区与待核实
- 仍会出错或证据不足的地方

## 下一课
1. 一个最自然的问题或迁移练习

## 关键来源
- 本课实际使用且值得复用的来源
```

## 向读书笔记沉淀

只有用户明确说“写入读书笔记”“整理成文章”或同等授权时才写入。写入前查重，优先更新相关原文章；若确需新建，默认只在 `10-文章/` 形成一篇完整文章。

文章以用户为什么觉得值得留下为中心。病例学习可保留“题目—我的回答—纠错—迁移—最终纪律”，但不自动附带独立课程记录、资源表或练习目录。
