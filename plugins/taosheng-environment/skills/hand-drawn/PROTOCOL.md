# 编号画风配方调用协议

仅在需要旧编号、其别名或完整提示词模板时读本页。视频流程见 [SKILL.md](SKILL.md)。

1. 按用户选择或内容需要确定画风。亲子题材不自动绑定蜡笔；未指定时可自行选并说明理由，不固定停下等菜单选择。
2. 运行 `python3 -B scripts/render_prompt.py --list` 查看参数，从 [STYLES.md](STYLES.md) 读取选定配方。保留完整配方，用脚本填主体、构图与文字，不把多个固定配方混为一个未验证样式。
3. 按 `scripts/render_prompt.py --help` 的实际参数调用，保留所需画幅。输出可能是文本或带参考图的 JSON；此脚本本身不生图。
4. 用户要图片时，用当前宿主图像工具执行调用包并审图；只要提示词时直接交付，不擅自生图。

## 稳定配方的专属合同

- **3.1**：正式采用时一并使用锚点与三阶段 workflow：基础、scribble-correction、scribble-chaos-correction。前两阶段为中间产物。这是该配方的复现要求，不是所有手绘都要画三次。
- **19**：正式 JSON、原创锚点、合同要求的模型条件与高保真参考输入；基础图为 candidate-only，按 acceptance_contract 验收。
- **20**：固定锚点生成 final-candidate，运行机读验收；失败候选按其合同重生成，不用泛化风格编辑冒充复现。
- 必要输入不受工具支持时，说明该命名配方未复现。用户未锁定它时可以另选可实现的画法，但不能标为原配方通过。
- 3.1/19/20 纯文本预览须用 `--text-only-preview`，不能当完整调用包。

参考图由 `assets/image-manifest.json` 登记，使用时核对文件与哈希，缓存可离线复用。缺图不静默省略。下载机制见 [图像托管实现](docs/image-hosting.md)。该文的公开托管属于上游仓库维护，不是本地生成图交付步骤；项目素材留在授权位置。
