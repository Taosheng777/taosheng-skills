- [画风与绘制计划](https://github.com/threerocks/sweety-handdraw-video/blob/5206ec0d17f9b353e400b64b9c51ad69e721e02a/skills/sweety-handdraw-video/references/style-and-drawing.md)：生图前考虑轮廓和独立部位，成图后的遮挡与叙事条件逐项检查。
- `caption_assets.py`、`subtitle_contract.py`、`audio-and-ending.md`：定时入口新增独立字幕字体、无底板/半透明底板；构建前检查字幕重叠、字形边界及声音超出视频。最终流和解码检查不自动填写视听验收。
- [托管素材](https://github.com/threerocks/sweety-handdraw-video/blob/5206ec0d17f9b353e400b64b9c51ad69e721e02a/skills/sweety-handdraw-video/references/hosted-assets.md)：5 张运行参考图增加 GitHub 镜像、按需缓存和离线复用。原始大小/哈希不改；镜像有独立字节校验值，3 张仅清理元数据的版本经过实际像素对照，原画、尺寸和既有锚点像素合同保持。

## 按任务取舍

本技能保留静态插画、无声、字幕配乐及已有音频能力；不强制新配音、六款音色、选项弹窗、广告水印、固定封面、统一笔顺或固定片尾。轮廓与填色顺序由内容和选用引擎决定。

没有复制上游约 1300 个文件的全部导演/动效依赖，也不自动安装 VoiceStudio、VoxCPM2、MLX、Bun 或云端供应商。方法和新增定时检查在本技能运行；上游新版的完整 production job 合同没有冒充为已经接入。

已有 `run_video.py` 与 `render_timeline.py` 仍使用 [本地引擎](本地引擎.md) 中提交 `216a199…` 加已验证补丁；本次没有改该引擎、现有项目配置或锁文件。升级引擎须在独立副本适配实际接口与素材，并完成代表段和回归后才能维护代码锁；不能直接把新提交写入锁。

来源版本记录用于复核，不表示任意主题、任意声音或全部上游实现已完成同等验证。
