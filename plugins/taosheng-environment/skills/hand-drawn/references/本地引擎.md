# 接入已有逐笔引擎

可复用 [threerocks/sweety-handdraw-video](https://github.com/threerocks/sweety-handdraw-video)，已检验版本 `216a199a4ee7bb85e777a145a6fc116ddf985809`。保留 MIT 许可与来源，它是可选实现而非唯一工具。

代码锁对应这一提交加本地绘制修正；可移植补丁为 [engine-drawing-fixes.patch](engine-drawing-fixes.patch)，从该提交的原始归档生成。新环境确需配置时，先把该引擎复制到授权的独立运行目录，再在副本内用 `patch -p1` 应用此补丁，之后运行入口的 `--inspect`。不要改另一个项目正在使用的引擎，不自动重签未知改动。

本技能不打包大型环境，不自动下载安装或调用声音服务。先检查项目已有引擎，按它的 `references/runtime-contract.md` 组织 job.json。任务数据写项目目录，不写引擎安装目录。

纯字幕、无声片或已有精确音频时间线，优先使用本技能的 [定时时间线](定时时间线.md) 入口；下面的 run_video.py 保留原引擎的配音驱动模式。

新配音先按 [声音与字幕](声音与字幕.md) 完成整篇母带，定时入口可直接使用；不要用旧引擎按 beat 生成的接口误称整篇连续合成。2026-10-13 吸收的上游 1.2.3 方法和新增定时检查见 [方法来源](上游方法来源.md)，与这里保持的引擎代码锁是两个版本层。

## 可执行入口

项目运行配置包含 `engine`（引擎内的 skills/sweety-handdraw-video 目录）、`python`（实际解释器），可选 `bin_dir`（FFmpeg 等位置）和 `preflight`（可信主机检查命令的参数数组）。路径均由项目传入，不照抄别的机器。

```sh
python3 scripts/run_video.py --config /实际项目/config/手绘运行环境.json doctor --job /实际任务
python3 scripts/run_video.py --config /实际项目/config/手绘运行环境.json build --job /实际任务
python3 scripts/run_video.py --config /实际项目/config/手绘运行环境.json render --job /实际任务 --preview --duration 12
python3 scripts/run_video.py --config /实际项目/config/手绘运行环境.json render --job /实际任务
python3 scripts/run_video.py --config /实际项目/config/手绘运行环境.json verify --job /实际任务
```

附加 `--inspect` 只检查配置与代码锁，不运行引擎。未知代码状态先审查再维护锁文件，不能静默忽略。入口不写原图、不生成声音、不改引擎、不自动填写画面审查。

以上 doctor/build/render/verify 保留旧引擎接口，只说明相应工程阶段。新制或完整重制仍须执行 [制作约定与最终检查](制作约定与最终检查.md)，不得把旧引擎的 verify 当作新版完整验收。`run_video.py finalize` 已改为共同的最终检查，需 job.json 的 contract 及 `--assembly /最终合成记录.json --video /实际成片.mp4 --review /真实审看记录.json`；不再仅调用旧引擎的 finalize。

## 已有实现经验

- 每句独立停顿可保持声音自然，已检验扩展接受 pause_seconds（0–6 秒）。
- 白底噪点会造成碎路径，white_key 是合成阈值；不能为去噪删掉淡色主体，要保留原图并看结果。
- 透明边缘 RGB 会污染 HSV 分区；排除颜色仅判断有效不透明像素，所有可见像素仍需合理归属。
- 音量滤镜完整输出后再截长度，避免丢失末尾缓冲；核对最终编码音轨收尾。
- weight 分配音频窗口中的相对绘制时间，不是秒数。
- 当前引擎有固定封面与配音约束，汉字是字形近似描线。无声字幕片、自定义片头或原生 SVG 等超出能力时，用合适实现或在独立副本修订验证；不制造假声音或假审查绕过。
- verify 只代表工程检查；finalize 需要真实且匹配当前视频的检查记录。

上游指南中的供应商、固定画风和秒数仅是选择该实现后的条件，不扩大用户需求或执行权限。
