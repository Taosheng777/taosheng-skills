# 连贯旁白、独立字幕与完整收尾

## 新声音先完成，再锁时间

先写完整稿 → 生成或录制整篇旁白 → 核对全文与声音 → 保存母带及哈希 → 取得真实逐句/逐词时间戳 → 安排绘制、换场和字幕 → 编码后复核最终音轨。

字幕句和镜头是母带上的标记，不是配音切口。不要因换图插入固定空白，也不要为了画完图压缩换气、截掉句尾或整体变速。生成能力不支持长稿时，在声音阶段按有上下文的语义段落完成编辑，核对衔接后导出完整母带，记录实际方式；不称为一次生成。

时间戳须来自真实对齐或转写，并结合原文核对。可在项目保存 `alignment.json`：母带和稿件的 SHA-256、原文、每段 start/end、采用的对齐工具与可疑处复核。时间相对母带起点，必须有限、有序、不重叠且在母带内。字数平均分配只能叫估算，不能假称精确同步。换声后重算对应时间戳；只换图时保留声音。

声音后端、音色与参考录音是不同选择；沿用本片已认可的方案。用供应商现有音色不必搭建本地模型；本地模型也不能仅凭合成成功就称音色自然。不把合成试听当作真实人物的原始录音继续克隆。

## 现有定时入口如何接入母带

`render_timeline.py` 接受完整声音文件。`audio.start` 为视频中的绝对开始秒数，默认 0；母带不含片头时可设为本片实际正文起点。已有混音已包含片头静音时保留 0，避免双重延迟。页面和字幕时间仍为全片绝对秒数，不加固定一秒。

```json
{"audio":{"source":"inputs/旁白母带.wav","start":0.8}}
```

构建前测音轨真实时长；开始时间加音轨时长超过视频结束一帧以上时拒绝构建，避免 `-t` 截尾。短音轨会补静音；停留是否合理仍须按片尾目的检查。此入口不合成、不转写声音，也不自动验证旁白原文。配乐和音效沿用任务要求，混音仍在声音层完成。

## 字幕只保留一个显示来源

准确字幕与手写标题分开。语音按完整短句显示，字幕不逐字闪动；按实际观看尺寸检查最密集画面、长句、换句和最后一句。单纯缩小字号不能补救阅读时间不足。

新定时任务可使用 `caption_style.mode=quiet`（白字黑边、无底板）或 `plate`（半透明底板），字幕字体独立于手写字体。沿用底部整块底板的旧任务保持 `footer`；省略 mode 继续按旧版处理。没有可靠常规字体时明确配置路径，不悄悄回退到手写字。

```json
{"caption_style":{"mode":"quiet","font":{"path":"/实际常规中文字体.ttc","index":0},"size":38,"bottom":54,"stroke_width":2}}
```

`size/bottom/max_width_ratio/max_lines/color/stroke_color` 可按画幅设置；`plate` 另接受 `background:{"color":"#243039","opacity":0.76}`。文字不自动删减或重新估算声画时间。构建前检查字形宽高、有限时间、有序且不重叠。无底板会显露更多手臂，代表段必须另查前臂断边和遮挡。

硬字幕来自一个可编辑字幕层。改字时从干净素材重新合成，不能叠在已有硬字幕上。交付页不再添加第二套 `<track>`；同名 SRT/ASS/VTT 放制作资料目录，避免播放器自动加载。用户需要软字幕时按该交付方式组织，不强制烧录。

```sh
python3 scripts/media_checks.py /实际成片.mp4 --burned-captions --decode
```

工具核对实际流、同名字幕文件和完整解码，硬字幕同时含字幕轨时报错；同名外挂文件报告风险，不能据此断言已经重复显示。画面烘焙的文字与播放器实时字幕须实际检查，不能由流检查证明唯一。

FFmpeg/ffprobe 未在当前命令的 PATH 时，加 `--bin-dir /项目已有工具目录`；不自动下载或安装。

## 末句与完成画面一起收住

指定结束语先写进完整稿，核对末句、末字、尾音、字幕、手部离场和完成画面。声音缺失或已截断时先修声音，补静音不能补回发音。渐隐放在本片需要保留的声音之后，不让末字仍在发音时全白或全黑。

可用波形/RMS或静音检测辅助判断外侧静音；上游的 10ms、−60dBFS 只是一种检测方法，配乐、低声和环境音会影响结果。片尾停留由阅读和叙事决定，不把上游 0.45 秒或 1.2 秒上限套用到院内片尾、署名或无声片。

局部换声优先保留已认可画面；长度未变时可保留视频码流。必须改时长时，以原/新真实边界做单调映射，再检查全部换图点；视频重新编码后只能称画面设计保留，不能称字节不变。只改字幕则保留声音，不重新生图或合成旁白。

工程检查、ASR、连续观看与主观听音分别记录；最终编码后的音轨需要再核对，母带通过不能代替成片通过。

检查使用最终合成器实际使用的声音与字幕。与 [制作约定](制作约定与最终检查.md) 核对，不能给中间资产传空字幕、无音轨就宣称整片检查完成。多角色按有上下文的语义段分别演绎可以合理，须记录原因和衔接核对，不伪称整篇一次合成；单一旁白仍优先连贯母带。完整听感未检查时保留 needs-review，ASR 只能用于文字内容核对。
