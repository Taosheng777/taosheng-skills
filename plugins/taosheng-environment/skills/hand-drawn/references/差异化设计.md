# 每条作品自己的表达

用于多作品、系列或用户指出重复的情况。目标不是随机换风格，而是让每条内容最重要的关系可见。

| 核心关系 | 可考虑的画面组织 | 绘制过程的作用 |
|---|---|---|
| 情绪或认知变化 | 同场景前后对照、近景表情、留白与局部点色 | 先显现困境，再补回应；颜色强调变化 |
| 有先后的行动 | 连续场景、路线、事件节点、可追踪道具 | 补全步骤，让先后和人物位置可追踪 |
| 因果机制 | 剖面、关系图、输入与结果、同条件对照 | 连接与变化同步，让原因如何作用可见 |
| 数量比较 | 同尺度图物、并列实验、量尺 | 先建立基准，再显现差值 |
| 技能示范 | 手与物体特写、动作姿态、完整一轮尝试 | 显示接触、方向与结束状态 |

这些是选择思路，不是必套模板，可按内容组合。

## 先作简短对照

每条只记核心问题、视觉主角、构图与镜头、线条与色彩、主要动作、节奏，以及为何适合内容。比较同批作品：换掉标题仍像同一条片子，就应改叙事和镜头。

通常至少在两个影响观看的维度形成区别，例如同场景近景变化与沿时间展开的事件路线。这是检查思路，不是凑数门槛。只换衣服、纸色、笔的袖子或片名不能解决重复。

连续角色可以保持身份，但姿态、视点、关系和道具由本片决定。跨片统一保持在用户要求的范围。

## 看实际帧和短段

去掉标题，能否从画面组织辨认主题？每一笔是否增加信息？是否几个镜头只换一句字幕？若所有片子都变成左边两人、右边三条建议，重排关键场景，而非堆装饰。

差异不能损害可读性，不能打乱事实顺序、角色关系或用户明确保留的元素。
