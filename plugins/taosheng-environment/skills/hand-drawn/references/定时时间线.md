# 定时绘制：字幕、已有配音与无声片

当阅读时间已确定，或必须保留已有音频位置时，使用 [render_timeline.py](../scripts/render_timeline.py)。它复用已验证引擎的笔迹、上色与手部模块，自行编排时间；不依赖新配音服务。

新制/完整重制先按 [制作约定与最终检查](制作约定与最终检查.md) 保存制作约定。在项目任务目录保存 `job.json`。下面是无声、有字幕、有手的路径示例；其约定对应 audio=none、captions=burned、hand=visible、drawing_mode=traceable、required_actions=[]：

```json
{
  "version": 1, "mode": "timed", "title": "本次主题",
  "contract": "制作约定.json",
  "canvas": {"width": 1920, "height": 1080, "fps": 30},
  "paper": "#FFFFFF", "cover_seconds": 0,
  "font": {"path": "/实际字体.ttf", "index": 0},
  "hand": {"preset": "navy"},
  "pages": [{"start": 0, "end": 6, "actions": [
    {"type": "path", "width": 600, "height": 300, "x": 180, "y": 170,
     "strokes": [[[40,60],[220,60],[220,180]], [[260,180],[500,180]]],
     "start": 0.3, "end": 4.8}
  ]}],
  "captions": [{"start": 0.3, "end": 5.8, "text": "已核对的完整短句"}]
}
```

所有时间为全片绝对秒数。每页与每次落笔须有序、不重叠；同一时刻只有一支主笔。页面结束前保留识别和阅读时间。支持 `text`、`marker`、`illustration`；后两种的坐标、部位与配方由 [本地引擎](本地引擎.md) 所述运行合同定义。插画的描线与填色顺序沿用当前引擎实现，不将它的顺序变成所有工具的统一要求。

关系图可用原生 `path` 动作：指定 width/height、局部坐标的 strokes（多条折线）、line_width 与 color，同样由持笔手按路径绘制。插画默认保留原始像素上限；需放大近景时显式设置 display_scale（0.1–4），同时核对分辨率和笔尖，渲染器会同步缩放笔迹定位。单个动作的 hide 可在绘完后、页面结束前隐藏，适合替换同一位置的说明。`hand.enabled=false` 隐藏手，必须与本次约定 hand=hidden 一致。封面期间的字幕也按绝对时间显示。

插画需提供 `source`、尺寸、可选 `crop` 和按实际图像标注的 `parts`。在顶层 `image_reviews` 记录每个输入的 `source`、当前 `sha256`、真实观察 `evidence` 和实际看过的 `approved_crops`。正式构建还要每个动作的 `part_review`，记录当前图片/裁切/几何的哈希与逐项观察。没有检查不能写已通过。先检查分区和路径时用 build --assets-only，它不会把资产标成完整视频。

`audio: {"source": "inputs/已核对声音.wav", "start": 0}` 可选，省略则导出无音轨视频。start 为全片绝对开始秒数，默认 0，完整母带可设为实际正文起点。它不会生成或验证旁白；提供短音轨时会补静音至视频结束，是否合适须检查。完整音轨超出视频一帧以上时拒绝构建，避免截断尾音。

`captions` 的完整文字稳定出现，不逐字闪动；手写标题单独用 text 动作。字幕在构建前检查有限时间、顺序、重叠、实际字形宽度与画布边界。`caption_style.mode` 的 footer 保留旧任务；quiet 使用独立常规字体、白字黑边、无底板；plate 使用半透明底板。字体、字号、宽度和实际观看检查见 [声音与字幕](声音与字幕.md)。独立字幕字体也纳入输入指纹。

```sh
python3 scripts/render_timeline.py build --config /项目/运行配置.json --job /项目/任务
python3 scripts/render_timeline.py frames --config /项目/运行配置.json --job /项目/任务 --times 1.2 3.8 5.8
python3 scripts/render_timeline.py render --config /项目/运行配置.json --job /项目/任务 --start 0 --duration 6
python3 scripts/render_timeline.py render --config /项目/运行配置.json --job /项目/任务
```

完整 build/render 会拒绝缺少制作约定、手部/声音/字幕不符、分区审查过期或逐笔帧预算不够的任务。资产时间线不能直接导出完整视频。带 --duration 或非零 --start 的诊断预览标为 preview，不能代替最终检查。

本定时渲染入口实现硬字幕与无字幕，软字幕请求会在构建前明确拒绝；使用支持软字幕的合成器并通过共同最终检查，不擅自改交付方式。

配置同 [本地引擎](本地引擎.md)，自动使用其中的 Python。部分渲染写 preview.mp4，完整渲染写 film.mp4；另存最终合成记录 composition.json、输出和任务哈希，并绑定本技能渲染/检查代码、约定及独立字幕字体。完整编码后自动执行工程检查，记录为 needs-review；真实审看片段/听音证据填写后再用 production_checks.py 复核。输入或代码变化后重新构建，不用旧记录宣称新版通过。
