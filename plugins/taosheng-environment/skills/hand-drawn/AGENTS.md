# 本地 hand-drawn 维护入口

当前能力与路由以 [SKILL.md](SKILL.md) 为准。此安装版包含插画、提示词和逐笔视频流程。

- `STYLES.md` 与 `scripts/render_prompt.py` 为编号配方库；保留编号、别名、参考图哈希和专属合同的兼容性。
- `PROTOCOL.md` 只用于调用编号配方，不把提示词工具的能力上限套到整个技能。
- 视频方法与画风解耦。只要某画风不强制绘画动画；要求逐笔视频不能只交付提示词。
- 项目内容、个人身份、客户资产与设备绝对路径不写入通用方法，运行配置由项目传入。
- 维护后运行 `scripts/check_skill.py`、受影响脚本的实际调用和宿主要求的工作流检查；不能改写通过状态掩盖失败。
- 视频执行维护须验证真实失败案例会被识别，并验证明确无手、无声与仅规划等合法路线。单元测试通过不能替代模型使用 Skill 的执行一致性检查；未进行新视频制作时如实说明验证范围。
- 上游资料作为方法和源码使用，不自动发布素材、开通服务或改其他技能。实际生成、网络和存储遵守当前宿主与用户授权。
